🍝 Salçalı Makarna Tarifi – HTML Ödevi
Bu projede temel HTML etiketlerini kullanarak salçalı makarna tarifi anlatılmıştır. Sayfa içerisinde başlıklar, paragraflar, bağlantılar, görseller, tablolar ve iframe gibi birçok HTML öğesi kullanılmıştır.

🛠 Kullanılan Teknolojiler
HTML5

Dahili (inline) CSS

📌 Sayfa İçeriği
Ana başlık ve açıklayıcı metin

Sayfa içi bağlantılar (#id kullanımı)

Salçalı makarna için malzeme listesi

Yapım aşamaları (ve görsellerle desteklenmiş adımlar)

Tarif önerileri ve püf noktaları

Harici bir tarif sitesine gömülü iframe

İçecek tanımları

Kişisel bilgiler içeren tablo

Öğrenciler tablosu (renkli satırlarla)

CSS'in ne amaçla ortaya çıktığını anlatan bir bölüm
